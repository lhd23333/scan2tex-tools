# 扫描书籍图像增强/预处理 开源工具调研（图像篇）

> 调研时间：2026-10-07（stars/license/最近提交为 GitHub API 实测值）
> 环境约束：Windows 11 + RTX 5060 Laptop (8GB VRAM, **sm_120 Blackwell**) + Python 3.12

## 核心结论

1. **ScanTailor Advanced** 是整本书批处理的第一步（分页/纠斜/裁边/二值化/去斑，可批量、结果可预测、完全不依赖 GPU）。
   用活跃 fork：`ScanTailor-Advanced/scantailor-advanced`（344★，v1.2.1=2026-05；**Windows 装 v1.1.1 x64 zip**，2026-04 构建，带中文语言包）。
   ⚠️ 原上游 `4lex4/scantailor-advanced`（1.5k★）2020-05 已停更；`scantailor/scantailor` 原版已 archive。
   ⚠️ GitHub 上有名字相近的 SEO 垃圾组织 `Scan-Tailor-Advanced`，只认上面的确切 URL。
2. **Real-ESRGAN 对文字会"幻觉笔画"**（凭空造细节），通用 x4plus 直接用于教材文字有风险〔已验证：官方承认 + 社区共识〕。
   **但**：`realesrgan-ncnn-vulkan` 命令行版解压即用（免 Python/免 CUDA，Vulkan 后端），可当推理引擎换模型。
3. ⭐ **SourceBook 模型**（`tumuyan/SourceBook-Dataset`，417★，2026-05 活跃）：**中文社区专为扫描书训练的 2x 超分模型**
   （中文书籍页 + 思源字体合成训练），Release 提供 Windows ncnn 预编译包。**比通用 Real-ESRGAN 对中文文字安全得多。**
4. ⭐ **DN_SuperBook_PDF_Converter**（`dnobori/DN_SuperBook_PDF_Converter`，892★，AGPL-3.0，v2.00=2026-01）：
   **Windows 原生一站式扫描书增强**（去污渍/透印/晕墨/JPEG 伪影 + AI 增强 + 可选 OCR 出 Markdown），要求 Win10/11 + NVIDIA CUDA。
   ⚠️ 文档为日文。
5. **DocRes**（CVPR 2024，668★，MIT）能一个模型干 去弯曲/去阴影/去模糊/增强/二值化，但 `requirements.txt` 钉死
   `torch==1.11.0+cu113` + `numpy==1.21.6` —— **Python 3.12 装不上、RTX 5060 跑不了**，要自己放宽依赖。嫌麻烦走 `AdemBoukhris457/Doctra`（pip 装、中文文档）。
6. **Gemini 提到的 "BookOCR / Book-Cleaner" 判定为不存在**〔已验证：400+ stars 量级无此项目；同名仓库是不相干的小工具〕。
7. **环境红线**：RTX 5060 = sm_120，PyTorch 必须 ≥2.7 + cu128（`--index-url https://download.pytorch.org/whl/cu128`）。
   网上多数 Real-ESRGAN/DocRes 教程还在 cu113/cu118，照抄必崩。**优先选 ncnn-vulkan / C# 原生类工具可绕开 CUDA 版本地狱。**

### 去扭曲新一代（研究代码为主，暂不投入）
DewarpNet (cvlab-stonybrook, 627★, MIT) / UVDoc (246★, MIT) / DocTr-Plus (545★) / DvD (SIGGRAPH Asia 2025, AGPL) / DocDiff (361★, MIT，自带中文印章数据集)

### 场景文字超分（不推荐用于扫描书）
DiffTSR / MARCONet / MARCONet++ / TATT / TPGSR —— 训练域是街拍招牌，与扫描书内页退化模型不同，迁移效果存疑。
`TextSR` 未找到官方仓库（不编造）。

## 建议流水线（对本机最省事）

```
扫描图 (150 DPI 彩 / 96 DPI 低清)
  → ScanTailor Advanced（分页/纠斜/裁边/二值化/去斑）        [免 Python]
  → 96 DPI 那批追加：Real-ESRGAN-ncnn-vulkan + SourceBook 2x [免 Python]
  → 仍有弯曲/阴影的页：DocRes（或 Doctra）                    [需改依赖]
  → 需要文字：MinerU（本机已部署）/ Umi-OCR / OCRmyPDF
```
